# Portfolio audiovisual

Portada minimalista de Arturo Gómez Cáceres, creada con HTML y CSS.

## Añadir el vídeo de highlights

Sube tu reel en formato MP4 al directorio principal del repositorio y llámalo exactamente `highlights.mp4`. La portada lo reproducirá automáticamente en silencio y en bucle; los controles permiten activar el sonido o pausarlo. Los navegadores requieren que el vídeo empiece silenciado para permitir la reproducción automática.

La página está publicada con GitHub Pages y se actualiza al guardar cambios en la rama `main`.
