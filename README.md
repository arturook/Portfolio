# Portfolio audiovisual

Portfolio web de Arturo Gómez Cáceres.

La primera pantalla muestra únicamente el nombre y el vídeo de highlights. El menú y el resto de secciones aparecen al desplazarse hacia abajo.

## Añadir el vídeo de highlights

Sube el vídeo en formato MP4 al directorio principal del repositorio y llámalo exactamente `highlights.mp4`. Se reproducirá automáticamente en silencio y en bucle; los controles permiten activar el sonido o pausarlo. Los navegadores requieren que el vídeo empiece silenciado para permitir la reproducción automática.

Los trabajos, la biografía y el correo de contacto se pueden completar en `index.html`. La página usa GitHub Pages y se actualiza al guardar cambios en la rama `main`.
